# 计分与时间维度细则（满分 100 分 · v4.1 二次方梯度与强耦合扣分闸门版）

唯一权威参数配置源见 [`configs/benchmark.json`](../configs/benchmark.json)。

## 评分生命周期：盲评先行，最后一键统一定稿合成
1. **选手收尾阶段**：选手在单轮或多轮排障收工后运行 `finish_rescue.py` 冻结交付快照，随后仅运行 `timing_audit.py` 与 `judge_pack.py` 提取脱敏探针通过状态与客观覆盖率硬锚点表写入匿名盲评包（`leaderboard/blind/<pack_id>/`），**此阶段绝不计算也不落盘正式得分文件**。
2. **盲评阶段**：独立评委仅阅读匿名盲评包，严格对照事实卡顶部的**客观覆盖率硬锚点表**，通过 `judge_submit.py` 提交主观分 `D`（写入 `leaderboard/reviews.jsonl`）。
3. **最终定稿与合成阶段**：所有盲评完成后，评测发起人手动运行 `python leaderboard/finalize.py`，一次性对冻结交付物与各轮门禁快照重新执行官方脚本客观分定稿（`A(62) + B(0起扣分) + C(12) + T(6) = 80` 分，落盘 `runs/<run_id>/评分.json`）并与盲评 `D` 分（20 分）统一合成为 100 分制总分，生成裁决留档与总榜。

---

## 总分构成：客观自动分（80 分）+ 盲评主观分（20 分）

### A 层：60 项跨层暗病根因修复与 48 项全库脏账订正（62.0 分，含轮次阶梯折扣与二次方凸梯度）
- **三轮预发定性门禁与阶梯系数（`1.00 / 0.85 / 0.70`）**：
  - 选手每局最多可提交 3 轮 `checkpoint_round.py` 定性门禁巡检。门禁仅按**七大业务域**返回「已闭环 / 仍有异常未闭环」定性信号（严格隐去题目分母、具体失败项、伪反馈陷阱及封账红线状态）。
  - 系统在每轮回执打印前自动冻结不可变阶段快照，最终 `finalize.py` 出榜时逐项核对每个独立故障单元或脏账检查项首次完整闭环的轮次：**第 1 轮（零回执提示前）闭环计 `100%`（`1.00x`）**；**第 2 轮闭环计 `85%`（`0.85x`）**；**第 3 轮或最终封包补齐闭环计 `70%`（`0.70x`）**；最终交付未通过计 `0` 分。
- **二次方凸函数梯度（`a1_convex_exponent = 2.0`, `a2_convex_exponent = 2.0`）**：
  - 轮次折算后的线性得分率按平方映射至满分（`score_final = max_pts * (linear_score / max_pts) ^ 2.0`），显著拉开 90%+ 深水全闭环与 60%～75% 浅层局部修复之间的客观分差。
- **A1 六十项跨层暗病根因修复（满分 45.0 分，单元级全或无 All-or-Nothing 判分）**：
  - 共 **60 个独立故障单元（`BUG-01`～`BUG-60`）**，其中 **24 个（40%）为完全不在反馈单提及的零工单纯潜伏暗病**（潜伏暗病权重额外乘以 `1.3x` 后归一化至 `45.0` 分）。
  - **严格全或无（All-or-Nothing）**：每个 `BUG-XX` 包含多条正反例行为探针断言，必须全部通过才计该单元分值，修一半漏一半计 `0` 分。
  - 七大业务域分布：
    1. **域 1 计量归集与套餐协议链路（`BUG-01`～`BUG-09`）**
    2. **域 2 钱包双账本与自动结算链路（`BUG-10`～`BUG-18`）**
    3. **域 3 多币种锁汇与跨境财资链路（`BUG-19`～`BUG-24`）**
    4. **域 4 金税数电票与跨期调账链路（`BUG-25`～`BUG-31`）**
    5. **域 5 复式总账与递延摊销链路（`BUG-32`～`BUG-38`）**
    6. **域 6 渠道分润与催收内控链路（`BUG-39`～`BUG-50`）**
    7. **域 7 安全导出前端与开放期平账链路（`BUG-51`～`BUG-60`）**
- **A2 240 租户全库脏账不变量审计与封账红线（满分 17.0 分，共 48 项核验）**：
  - 反馈单零点名受灾客户，选手须自行扫描全库订正 `2026-11`（`OPEN`）期 **44 项行级异构脏账**；
  - 重算修平 `2026-11` 开放期 **3 大全局子账本**（复式总账试算平衡与应收勾稽、渠道代理商返佣清分、多期递延收入摊销表）；
  - **封账铁律与跨期调账**：`2026-09` 与 `2026-10`（`CLOSED`）历史账单、总账分录、已确认摊销及归档总额保持字节级零篡改，同时为两笔已查明的历史封账超收错单在 `2026-11` 登记准确的跨期贷项调账单，且不误伤健康大客户账单。

### B 层：24 项强耦合防误伤与合规特例扣分闸门（0 分起扣，无免费底分）
- 共 **24 项回归与规则定力探针（`R01`～`R24`）**：除跨代兼容与伪需求拒绝定力外，内置 **8 枚与高频修复链路同处一室的强耦合连带损伤雷**（边缘网关 `HEARTBEAT_PING` 零用量干跑探活、无税收居民证明时的 30% 法定预提税、CSV 纯负数/负百分比免误加单引号、小额 `<5,000` 元退费快审免双签、导出根目录下合法月份子目录读取、启动期兼容热补丁选择性保留、`ACTIVE_LEGACY` 老客户豁免自动关停、`INTERNAL_FINANCE_DESK` 内部财务审计只读调阅）。
- **纯扣分闸门**：`B = -3.0 * failed_count`——不设“躺平白拿 20 分”的免费底分，每破坏 1 项合规特例或既有契约直接倒扣 **`3.0` 分**。
- **高压红线全局惩罚（`0.65x`）**：若触发破坏 v1 老租户兼容（`V1_LEGACY_BROKEN`）、开启未完备 V3 管线（`V3_PIPELINE_ENABLED`）、放行违规虚开发票（`ILLEGAL_FAPIAO_ALLOWED`）或篡改 `CLOSED` 已封账历史数据（`CLOSED_PERIOD_TAMPERED`），客观总分额外乘以 **`0.65` 全局惩罚系数**。

### C 层：外科手术精准度与细粒度突变测试（12.0 分）
- **C1 外科手术精准度（6.0 分）**：
  - 统计生产源码有效变更行数（排除测试、文档报告与数据文件）：`260～900` 行得满分 `6.0` 分；`900～2000` 行线性降至 `3.0` 分；`2000～3200` 行线性降至 `0` 分；`> 3200` 行或零代码改动得 `0` 分。
  - **死代码与高仿孪生文件误改惩罚**：每误改 1 个未挂载历史归档目录或活跃目录下的高仿未挂载孪生文件（共 23 个归档目录 + 19 个未挂载单文件），从 `C1` 倒扣 **`0.25` 分**。
- **C2 细粒度按测试方法突变检验（6.0 分）**：
  - 基于 AST 差分提取选手新增或修改的每个独立 `test_*` 方法，逐个在**未修复初始模板**与**选手交付快照**上隔离执行：仅当该方法在未修复原件上真实失败且在交付快照上真实通过时，才计为 **1 个有效抓错测试方法**。
  - 得分公式：`C2 = round(6.0 * min(1.0, valid_catching_methods / 18.0) * pass_ratio, 3)`（需至少 **18 个**独立有效抓错测试方法且修复件全绿拿满 `6.0` 分）。

### T 层：端到端排障效率与质量非线性封顶（6.0 分）
- 全链路校验不可伪造的开局锚点 `t0`、各轮门禁耗时（`R1 / R2 / R3`）与封包终点 `t1` 的端到端墙钟总耗时 `elapsed_minutes`。
- **衰减参数**：满分阈值 `M = 15.0` 分钟，半衰期 `H = 45.0` 分钟：
  - 当 `elapsed <= 15.0` 分钟时，`T_raw = 6.0`；
  - 当 `elapsed > 15.0` 分钟时，`T_raw = 6.0 * 0.5 ^ ((elapsed - 15.0) / 45.0)`。
- **核心成果非线性联合封顶**：`T = min(T_raw, 6.0 * ((A / 62.0) ^ 1.2) * max(0.0, 1.0 + B / 24.0))`。

### D 层：诊断归因与工程处置分寸（20.0 分，带客观覆盖率硬锚点封顶的匿名盲评）
- **D1 跨层根因与潜伏暗病归因准确度（0～8 分）**
- **D2 高仿伪需求、过期文档与合规边界定力（0～6 分）**
- **D3 外科手术修复与全库脏账订正工程合理性（0～6 分）**
- 盲评包自动计算并置顶**客观覆盖率硬锚点表**（详见 [评委盲评指南](judge_guide.md)），对遗漏零工单潜伏暗病、踩中回归陷阱或漏修脏账的报告实施强制得分封顶。
