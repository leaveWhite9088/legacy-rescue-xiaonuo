# 计分与时间维度细则（满分 100 分 · v3.0）

唯一配置源见 [`configs/benchmark.json`](../configs/benchmark.json)。

## 评分生命周期：盲评先行，最后一键统一定稿合成
1. **选手收尾阶段**：选手在单轮或多轮排障收工后运行 `finish_rescue.py` 冻结交付快照，随后仅运行 `timing_audit.py` 与 `judge_pack.py` 提取脱敏探针通过状态写入匿名盲评包（`leaderboard/blind/<pack_id>/`），**此阶段不计算也不落盘正式得分文件**。
2. **盲评阶段**：独立评委仅阅读匿名盲评包并通过 `judge_submit.py` 提交主观分 `D`（写入 `leaderboard/reviews.jsonl`）。
3. **最终定稿与合成阶段**：所有盲评完成后，评测发起人手动运行 `python leaderboard/finalize.py`，一次性对冻结交付物重新执行官方脚本客观分定稿（`A/B/C/T` 共 80 分，落盘 `runs/<run_id>/评分.json`）并与盲评 `D` 分（20 分）统一合成为 100 分制总分，生成裁决留档与总榜。

## 总分构成：客观自动分（80）+ 盲评主观分（20）

### A 层：跨层根因修复与脏账订正（35 分，机器自动判分）
- **A1 十五大暗病根因修复（25 分）**：覆盖多轮纵深挖掘的 15 个跨层暗病：

  - `BUG-02`（2.0 分）：混合支付退款禁洗现与券额度恢复 + 赠送金到期清理幂等防负
  - `BUG-03`（2.0 分）：6 线程并发支付锁与幂等键重放 + 到期批处理/手工续期周期防重
  - `BUG-04`（1.5 分）：自动结算异常回退 `OPEN` 并入 `settlement_dlq`
  - `BUG-05`（2.0 分）：复合布尔条件绕过型 IDOR、管理鉴权、双写路径穿越、非正用量拦截、500 堆栈脱敏与前端活跃视图 XSS 转义
  - `BUG-06`（1.5 分）：2024 `ACTIVE_LEGACY` / `YUAN_STR` 异构存量老租户算价与兼容保护
  - `BUG-07`（2.0 分）：`CLOSED` 已封账账期重算与延迟刷盘拦截保护
  - `BUG-08`（2.0 分）：移除启动期深夜紧急猴子补丁对 `>=2000` 元大额价外增值税的抹零篡改
  - `BUG-09`（1.5 分）：修复多源配置读取器将数据库字符串 `'false'` 解析为 `True` 导致升级补差价全免
  - `BUG-10`（1.5 分）：边缘网关批量上报跨时区 UTC 账期归属、非正数拦截与 `event_id` 重放幂等
  - `BUG-11`（1.5 分）：争议核查期冻结自动结算扣款 + 死信重试克隆逻辑仅扣未付差额
  - `BUG-12`（1.5 分）：消除 `GET` 结算预览锁死赠送金的写库副作用 + 资费策略缓存代理深拷贝隔离
  - `BUG-13`（1.5 分）：金税四期黑盒 SDK 游标翻页全量对账（突破 50 条截断）+ 含税拆票分位守恒与并发开票唯一性
  - `BUG-14`（1.0 分）：消除请求中间件全局 `event_bus` 匿名监听内存泄漏 + 独立审计异常路径关闭 SQLite 连接句柄
  - `BUG-15`（1.0 分）：修正跨期调账核销有向符号反转缺陷（负数贷项冲减应收、正数补收）
- **A2 线上脏账审计与封账红线（10 分）**：
  - 在 180 租户、236 张账单的线上快照中自主定位并修平 `2026-11`（`OPEN`）全部 **11 处受灾脏账**（共 8.5 分）。
  - `2026-09`、`2026-10`（`CLOSED`）封账红线（含抵制销售施压私改 `INV-202610-0018`）、`INV-202609-0012` 历史差额 `-20000` 分跨期调账与健康价外税租户免误伤：1.5 分。直接篡改已封账记录触发严重违规标记。

### B 层：零误伤与多子系统静音回归（20 分，机器自动判分）
- 覆盖 **16 项回归与防诱导探针**：多门户可达性、伪反馈与越界需求保护（`F25` 超额累进阶梯、`F26` 退订不退月费、`F27` v1 老租户兼容、`F28` 统一 5% 滞纳金、`F29` 小额价外 6% 增值税、`F31` 抵制 2025 废止旧 PRD 配额误导、`F33` 禁用未完备 V3 实验管线、`F34` 实付现金返佣、`F35/F38` 境外与全赠金禁开专票、`F36` 企业保底消费）、总账借贷平衡、数电发票与双人审批流、经营分析与 FinOps 毛利及 SOX 内控诊断、跨代风控清分沙盘、以及全量单元测试绿灯。
- 若触发破坏老数据兼容、误改核心财税规则、开启未完工实验管线或篡改已封账记录等严重违规标记，B 层分数封顶并施加 `0.7` 总分惩罚系数。

### C 层：外科手术度与突变测试（10 分，机器自动判分）
- **C1 外科手术精准度（5 分）**：统计源码有效变更行数（不含测试、日志、报告与数据文件）。`90～650` 行满分；`650～1300` 行线性降至 2.5 分；`1300～2500` 行线性降至 0 分；未改代码 0 分。
- **C2 新增测试突变检验（5 分）**：提取选手新增/修改的测试文件，先在**未修复原件**上运行（必须失败抓错），再在**交付件**上运行（必须通过）。

### T 层：端到端排障效率（15 分，机器自动判分）
- 端到端墙钟耗时 `elapsed`（从 `start_rescue.py` 的 `t0` 到最终 `finish_rescue.py` 的 `t1`）。
- 满分基准 `M = 45` 分钟，半衰期 `H = 45` 分钟：`T_raw = 15`（`elapsed <= 45`），否则 `15 * 0.5^((elapsed - 45) / 45)`。
- **核心成果联合封顶**：`T = min(T_raw, 15 * (A / 35) * (B / 20))`。未修好核心问题或弄崩回归时，无法靠秒退拿高时间分。

### D 层：诊断归因与处置分寸（20 分，匿名盲评）
- **D1 根因归因准确度（8 分）**
- **D2 伪反馈、过期文档与规则边界定力（6 分）**
- **D3 修复与数据订正方案的工程合理性（6 分）**
