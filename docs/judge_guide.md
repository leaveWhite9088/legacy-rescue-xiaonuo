# 评委盲评指南（D 层：20 分）

## 盲评原则
- 评委**仅**查看 `leaderboard/blind/<pack_id>/` 下的匿名事实卡（`case-XX.md`），不得查阅模型映射表（`leaderboard/blind-maps/`）或中心评审日志（`leaderboard/reviews.jsonl`）。
- 事实卡已展示客观核验摘要（探针通过情况、老数据与回归保护、代码改动规模、突变测试结果）及选手《事故排查与处置说明》原文。

## 评分维度与锚点
1. **D1 根因归因准确度（0～8 分）**
   - `4 分`：定位到一半以上主要根因，但存在表象归因。
   - `6 分`：绝大多数暗病（跨层传导、并发竞态、状态撕裂）归因准确，与客观探针结果一致。
   - `8 分`：7 大暗病根因全部定位精准、证据链清晰，无虚构结论。
2. **D2 伪反馈与规则边界定力（0～6 分）**
   - `3 分`：识别出部分伪反馈，但依据含糊。
   - `5 分`：准确区分 F11（累进阶梯）、F12（退订不退费）、F13（v1 老数据兼容）、F14（VIP 滞纳金越界需求）、F15（跨境不含税价外 6% 增值税正常计税）、F16（Webhook 自动重试成功的良性告警），未误改原有正确逻辑。
   - `6 分`：甄别依据扎实，对文档与代码实现边界给出清晰说明。
3. **D3 修复与数据订正方案的工程合理性（0～6 分）**
   - `3 分`：代码能跑通但改动偏大或脏账订正不够彻底。
   - `5 分`：改动外科手术精准、7 处未结清脏账订正准确、严守 `2026-09` / `2026-10` 已封账红线。
   - `6 分`：修复简洁优雅、并发锁粒度合理、跨期调账与回归测试完备可审查。

## 提交命令
```sh
python src/scoring/judge_submit.py --pack-dir leaderboard/blind/<pack_id> --case-id case-01 \
  --judge-id <评委ID> --judge-model <评委模型> \
  --D1 <0-8> --D2 <0-6> --D3 <0-6> --evidence "[引用的事实卡证据]" --note "<简短评语>"
```
