# 多角色线上问题反馈汇总单（近一周客服 / 运营 / 财务 / 安全 / 运维群整理）

以下为近期各渠道收集到的 16 条原始口语化反馈。注意：一线反馈中可能混杂同一根因的不同表象、客户对计费/税率规则的误解、良性瞬态告警以及违反公司制度的越界诉求，请结合系统日志、数据库快照与《产品与账务规则》逐一甄别。

- **F01（大客户群 - 云图数据 & 瀚海物联）**：我们两家都是月初用高配套餐，月中降级成了基础版。奇怪的是降级操作成功后，门户页面上好几分钟显示的还是老套餐配额；更离谱的是最近出 11 月账单，居然把降级前在高配套餐额度内（或当时套餐下）跑的调用量全混进基础版里重算超额费，平白多收了上千块！
- **F02（客服 - 小张）**：有个叫“飞跃零售”的客户，之前充了 100 块现金、领了 200 块活动赠送金，付 199 块账单时全扣的赠送金；前两天客服给他做了 100 块部分退款，结果他账户里可提现的现金余额居然变成 200 块了！赠送金怎么能洗成真金白银？
- **F03（财务 - 李姐）**：我在运营财务后台巡检钱包时，看到“锐捷医疗”的赠送金余额居然是 `-160.00` 元！赠送金到期清零怎么还能扣成负数？
- **F04（租户投诉汇总）**：有客户反馈网络抖动时连点了两下支付按钮，或者手点支付刚好撞上零点自动扣款任务，同一张账单竟然被扣了两次钱！而且带同一个幂等键重试好像也没拦住并发。
- **F05（运营 - 老王）**：11 号零点批处理跑完后，发现“星河传媒”在同一个 11 月计费周期里被连续开了两张一模一样的未付续费账单，麻烦查查是不是定时出账和续费接口撞车了，把重复多开的那张处理掉。
- **F06（客服 - 小张）**：后台有好几张 11 月账单一直卡在 `PENDING_SETTLE`（结算中）好几天动不了！我核了一下，“蓝海智造”那边钱包流水明明已经扣完款了，账单却还显示未付结算中；而另一家“千帆供应链”是因为余额不够没扣成，但状态也死锁在结算中既不能充值重付也不进死信队列。
- **F07（安全巡检通报）**：内网渗透测试扫出几处高危问题：① 普通租户把接口里的账单号改成别人家的，居然能直接读取他人账单详情甚至提交争议；② `/api/admin/jobs/run` 和 `/api/admin/reconcile/export` 两个管理接口漏了管理员鉴权；③ 对账文件导出接口虽然写了 `replace("../", "")`，但双写绕过或反斜杠照样能跨目录读源码；④ 服务端 500 报错直接把 Python 堆栈吐给前端了。
- **F08（测试 & 运营反馈）**：用量上报接口 `/api/usage/events` 传 `quantity: -500` 或 `0` 居然能成功入库冲抵用量！另外租户提交争议原因或者企业名称里如果带 `<script>` / `<img onerror>` 标签，门户和管理台表格渲染时会直接触发脚本执行。
