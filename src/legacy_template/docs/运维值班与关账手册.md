# 云策账务中心 — 运维值班、批处理调度与安全合规手册

## 一、核心批处理作业（`app/jobs/`）职责清单

线上后台通过管理接口 `POST /api/admin/jobs/run`（需携带管理员密钥 `X-Admin-Key`）按固定次序触发以下核心作业：
1. `flush_usage`（`app/jobs/metering_flush_job.py`）：将 `usage_events` 中未刷盘（`flushed=0`）的计量明细聚合写入 `usage_summaries`。注意：若收到归属已封账历史账期（`CLOSED`）的迟到话单，严禁直接改写历史封账期汇总与历史账单，必须折算差额记入当前 `OPEN` 账期的 `billing_adjustments`。
2. `generate_invoices`（`app/jobs/settlement_job.py`）：扫描到期需续费订阅，调用计费引擎开具周期账单并推进周期起止日（必须防止与租户手工立即续费并发重单）。
3. `settle_invoices`（`app/jobs/settlement_job.py`）：扫描 `OPEN` 账单执行自动扣款；若余额不足或扣款抛错，必须确保状态回退至 `OPEN` 并登记 `settlement_dlq`，绝不允许遗留在 `PENDING_SETTLE` 卡死态。
4. `expire_promos`（`app/domain/ledger.py`）：清理已过期的赠送金券（`promo_grants`），仅可幂等扣减尚未消费的 `remaining_cents`，严禁重复扣减或按 `initial_cents` 超扣导致赠送金池变负。

## 二、安全与权限基线要求

1. **租户隔离（Anti-IDOR）**：任何携带 `X-Tenant-Token` 的门户接口（包括查询单张账单详情、发起账单争议申诉、申请发票等），必须严格校验目标单据的 `tenant_id` 与当前登录租户一致，跨租户访问一律拦截（返回 `403`）。
2. **后台接口鉴权**：所有 `/api/admin/*` 下的管理操作、批处理触发与对账单导出接口，必须强制校验管理员凭证 `@require_admin`。
3. **文件导出路径安全**：对账文件下载导出路径解析（`app/infra/security.py`）必须基于规范化真实路径（`Path.resolve()`）严格限制在 `EXPORT_DIR` 目录内部，防范 `....//` 或编码绕过等目录穿越读取。
4. **计量入参校验与生产错误脱敏**：上报 API 用量事件必须拒绝 `quantity <= 0` 的非法负数冲抵请求；生产环境下全局 500 异常处理器严禁向客户端响应体泄露 Python 堆栈源码路径。
5. **前端防 XSS**：门户账单列表展示 `dispute_reason` 与管理后台展示租户 `company_name` 等用户输入字段时，必须经过 HTML 转义或使用安全的文本节点绑定，严禁将未转义字符串直接拼入 `innerHTML`。
