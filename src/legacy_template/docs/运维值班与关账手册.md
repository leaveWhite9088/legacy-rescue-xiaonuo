# 云策账务中心 — 运维调度与月度关账标准作业程序（SOP）

## 一、日常批处理调度顺序

夜间定时任务与管理端批处理触发入口按以下阶段依次运行：
1. **计量归集刷盘**：将缓冲表未刷盘事件按租户、账期及事件对应套餐汇总写入 `usage_summaries`。
2. **到期续费出账与自动扣款**：为符合续期条件的到期订阅生成新周期账单，并拉起钱包自动结算，异常单据进入死信队列等待后续差额重试。
3. **赠送金清理、SLA 巡检与逾期催收**：清理已过期赠送金批次；扫描并闭环月度 SLA 可用性赔付单；评估逾期账单催收等级、计提逾期违约金并联动租户停复机状态。
4. **月度子账本批处理**：生成当期渠道返佣清分表、多月合同递延收入摊销计划与复式总账记账凭证。

## 二、月度预关账四项账务平衡核对清单

每月末执行正式封账（`CLOSED`）前，财务与运维团队需确认当前开放账期（`OPEN`）满足以下平衡条件：
1. **应收账单与实收流水一致**：有效账单的应付金额、税额、违约金及已付金额准确无误，无重复出账、悬空卡死状态或超额重复扣款。
2. **钱包与赠送金台账守恒**：租户现金池与赠送金池余额与底层资金流水、未过期活跃赠金批次保持勾稽一致，无负余额穿透或试算锁券残留。
3. **复式总账与递延摊销守恒**：当期复式总账借贷总额相等且应收账款净变动与有效账单总额一致；多月合同按不含税净额摊销且各期累计确认额守恒。
4. **销项发票与渠道清分准确**：数电蓝红票价税分位守恒、状态完备，渠道当期返佣与历史锁定记录无误；已封账历史期间（`CLOSED`）全部账表记录保持原貌零变动。
