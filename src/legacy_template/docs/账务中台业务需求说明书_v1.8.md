# 账务中台业务需求说明书（v1.8）

- **文件编号**：YC-PRD-2025-108
- **发布日期**：2025-06-10
- **产品负责人**：商业化中台产品组
- **评审状态**：产研联席评审通过

## 1. 标准版套餐拉新配额标准
- `STARTER`（基础版）：定价 `199.00` 元/月，月度基础包含 API 调用配额设定为 `15,000` 次/月，超出部分按阶梯单价计收超额调用费；`PRO` 版包含 `50,000` 次/月；`ENTERPRISE` 版包含 `300,000` 次/月。
- 针对月调用量突破最高阶梯门槛的战略大客户，支持在专属价目表中申请按期末总超额量直接套用最末档优惠单价全量回溯计费。

## 2. 升配补差动态配置开关
- 系统在 `sys_runtime_configs` 动态配置表中维护 `waive_upgrade_proration_promo_window` 布尔参数：当运营开启升配免补差活动窗口（配置值为真）时，客户期中升级高阶套餐免收当期剩余天数差价；日常非活动期（配置值为假）按剩余周期天数比例补收月费差额。

## 3. 第三代统一流式计费流水线（V3 Pipeline）演进规划
- 为逐步收敛早期多版本算价分支，架构组在 `app/v3_pipeline/` 下构建新一代模块化计费管线，通过全局特性开关 `ENABLE_V3_BILLING_PIPELINE` 控制流量切换，并配套提供 `shadow_comparator` 只读影子比对器用于线上抽样核验。
