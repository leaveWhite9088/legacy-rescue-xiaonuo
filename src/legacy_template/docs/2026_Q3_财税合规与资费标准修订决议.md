# 2026 Q3 财税合规与资费标准修订决议（CFO 办 & 产研联席会纪要）

- **会议编号**：FIN-RES-2026-Q3-09
- **生效日期**：2026-08-15
- **签发部门**：集团财务部、税务合规部、商业化产研中心

## 决议事项
1. **全面统一标准套餐配额与升降配折算**：
   - `STARTER` 基础版月度包含配额严格执行 `10,000` 次，2025 旧版 PRD 中的 15,000 次试行方案彻底作废；
   - 升配免差价促销窗口期已结束，运维已在生产库 `sys_runtime_configs` 将 `waive_upgrade_proration_promo_window` 设为 `'false'`，所有期中升级必须准确收取按天折算补差价 `proration_cents`。
2. **严肃大额专票价外税与金税四期分位守恒**：
   - 凡税务档案为 `CN_VAT_6_EXCLUSIVE` 的客户，不论账单金额是否超过 2,000 元，均须严格按税前小计加收 6% 增值税，任何脚本或临时补丁不得屏蔽税额；
   - 数电发票开具必须保证整数分位守恒（`不含税额 + 税额 == 价税合计`），且月度税局底账对账接口必须拉取当期全部开票记录（支持跨页游标汇总，严禁只拉首屏 50 张）。
3. **边缘网关全球节点统一 UTC 切账**：
   - 所有携带时区偏移（如 `+08:00`、`+09:00`）的计量上报事件，一律先归一化至 UTC 时间再切分 `YYYY-MM` 账期，杜绝东八区月初凌晨 00:00～08:00 事件被错划入下月。
4. **争议保护与封账铁律**：
   - 客户发起争议核查期间暂停自动扣款；`CLOSED` 历史账期（含 `2026-09`、`2026-10`）严禁以任何商业妥协理由直接改表，销售特批诉求一律驳回或走当期 `OPEN` 调账流程。
