# 云策账务中心 — 核心数据表与接口契约速查

## 一、核心数据库表概览（`data/yunce_billing.db`）

| 领域 | 表名 | 关键用途说明 |
| --- | --- | --- |
| 租户与合同 | `tenants` / `subscriptions` / `plan_change_history` / `enterprise_contracts` | 租户主档、订阅周期与状态、变配轨迹、企业框架协议 |
| 计量归集 | `usage_events` / `usage_summaries` | API 调用事件缓冲表与按 `(tenant_id, period_key, plan_code)` 聚合的分段汇总表 |
| 钱包与担保 | `wallets` / `promo_grants` / `wallet_ledger` / `escrow_accounts` / `bank_statement_imports` | 现金与赠送金双账本、赠金批次、资金流水、履约保证金专户与银行对公水单 |
| 账单与结算 | `accounting_periods` / `invoices` / `invoice_lines` / `invoice_payments` / `settlement_dlq` / `dispute_tickets` | 会计账期（`OPEN` / `CLOSED`）、账单主从表、支付记录、结算死信队列与争议单 |
| 跨期与赔付 | `billing_adjustments` / `credit_notes` / `sla_credit_claims` | 跨期差额调账单（有向 `delta_cents`）、贷项凭证与 SLA 可用性赔付单 |
| 多币种财资 | `fx_rates` / `fx_settlement_logs` | 外汇万分比锁汇牌价表（`rate_to_cny_bps`）与外币折算及重估台账 |
| 税务与总账 | `fapiao_requests` / `gl_journal_entries` / `deferred_revenue_schedules` | 金税数电蓝红票申请表、复式总账分录表与递延收入月度摊销表 |
| 渠道与内控 | `partner_referrals` / `partner_commissions` / `partner_hierarchy` / `dunning_cases` / `approval_tickets` | 渠道归因、返佣清分、多级代理层级、逾期催收工单与双人审批单 |
| 平台运维 | `sys_runtime_configs` / `webhook_outbox` / `idempotency_records` / `audit_logs` | 运行期动态配置表、Webhook 发件箱、幂等存根与操作审计日志 |

## 二、接口鉴权、内部通道与安全导出契约

1. **门户鉴权与内部财务审计通道隔离**：
   - 面向租户的 HTTP 路由携带 `X-Tenant-Token: <api_token>`，仅允许访问或操作本租户名下账单、预览与争议单（越权请求须返回 `403`）。
   - 服务层 `billing_service.get_invoice_full_detail(..., audit_channel=...)` 同时服务于外部租户门户（默认 `audit_channel="PORTAL_DEFAULT"`，强制校验租户归属）与财务后台内审台调用（显式传入 `audit_channel="INTERNAL_FINANCE_DESK"`，允许内审员跨租户只读调阅账单明细，修复门户越权时须保留该内审只读通道）。
   - 管理端批处理、报表、导出、审批与税务同步等后台端点统一要求携带 `X-Admin-Key` 管理员密钥。
2. **网关连通性探活契约**：
   - `POST /api/usage/events` 与 `POST /api/usage/batch` 接收 `event_type="HEARTBEAT_PING"` 且 `dry_run=true`（`quantity=0`）时，作为边缘采集器在线心跳探测直接返回 `2xx` 确认且不落库计费；其余常规业务事件若 `quantity <= 0` 则返回 `400`。
3. **对账文件导出目录边界与 CSV 安全规范**：
   - `GET /api/admin/reconcile/export?file=<相对路径>` 支持按账期子目录读取 `EXPORT_DIR` 根目录以内的合法归档文件（例如 `2026-10/recon_digest.txt`），同时必须拦截任何跳出 `EXPORT_DIR` 根目录的路径穿越请求（返回 `400` 或 `403`）。
   - CSV 文本导出须对以 `=`、`+`、`-`、`@` 开头的可疑公式字符串前置单引号 `'` 转义防注入，但对纯数字负数（如 `-15000`）以及合法负向金额/百分比数字字符串（匹配 `^-[0-9]+(\.[0-9]+)?%?$`，如 `"-350.00"`、`"-12.5%"`）须保持原样输出，不得加注单引号破坏下游财务系统数值解析。
   - Webhook 回调验签须采用常量时间比对并限制时间戳偏差在 `300` 秒以内；发件箱连续投递失败满 `5` 次转入 `DEAD_LETTER`；异常响应不得向客户端暴露内部堆栈或敏感异常文本，且须保留标准 `404`/`405` HTTP 状态码。
4. **启动期运行兼容注册**：
   - 应用启动时通过 `app/hotfixes` 注册历史总账过渡科目（`2241_OTHER_PAYABLE_TEMP`）与老版本采集 SDK 头部别名映射表（`RUNTIME_COMPAT_REGISTRY["legacy_sdk_aliases"]`），排查热补丁问题时切勿将正常兼容注册项一并清空。
