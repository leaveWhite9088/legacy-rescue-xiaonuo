# 云策账务中心 — 核心数据表与 HTTP 接口速查手册

## 一、核心账务数据库表（`data/yunce_billing.db`）

| 表名 | 核心用途与关键字段说明 |
| --- | --- |
| `tenants` | 租户主档：`id`、`company_name`、`api_token`、`status`（`ACTIVE` / `SUSPENDED` / `ACTIVE_LEGACY`）、`tax_profile_code`、`schema_version`、`billing_metadata` |
| `subscriptions` | 订阅关系：`tenant_id`、`plan_code`（`STARTER` / `PRO` / `ENTERPRISE` / `LEGACY_FLAT_99`）、`status`、`cycle_start`、`cycle_end`、`auto_renew`、`legacy_contract_override` |
| `plan_change_history` | 套餐升降配审计轨迹：`tenant_id`、`old_plan_code`、`new_plan_code`、`effective_at`、`proration_cents` |
| `enterprise_contracts` | 大客户最低保底与专属折扣框架合同：`min_monthly_commit_cents`、`custom_overage_discount_bps`、`valid_from`、`valid_until` |
| `wallets` | 双账本实时余额快照：`cash_balance_cents`（现金池，>= 0）、`promo_balance_cents`（赠送金池，>= 0） |
| `promo_grants` | 赠送金发放批次明细：`initial_cents`、`remaining_cents`、`status`（`ACTIVE` / `EXPIRED` / `EXHAUSTED`）、`expires_at` |
| `wallet_ledger` | 资金变动流水总表：`entry_type`（`TOPUP` / `PROMO_GRANT` / `PAYMENT` / `REFUND` / `PROMO_EXPIRE`）、`cash_delta_cents`、`promo_delta_cents`、`ref_id` |
| `usage_events` | API 计量原始明细缓冲表：`quantity`、`plan_code_at_event`、`occurred_at`、`period_key`、`flushed` |
| `usage_summaries` | 按 `(tenant_id, period_key, plan_code)` 联合唯一键聚合的分段计量汇总表 |
| `accounting_periods` | 会计账期表：`period_key`、`status`（`OPEN` / `CLOSED`）、`archived_total_cents`（已封账账期严禁篡改） |
| `invoices` | 账单主表：`base_fee_cents`、`overage_fee_cents`、`tax_cents`、`late_fee_cents`、`total_cents`、`paid_cents`、`refunded_cents`、`currency_unit`（`CENTS` / `YUAN_STR`）、`status` |
| `invoice_payments` | 账单支付核销明细：`invoice_id`、`idempotency_key`、`cash_paid_cents`、`promo_paid_cents`、`total_paid_cents` |
| `billing_adjustments` | 跨期差额与迟到用量调账表：`ref_invoice_id`、`target_period_key`、`applied_period_key`（当前 `OPEN` 账期）、`delta_cents`、`reason` |
| `settlement_dlq` | 自动结算失败死信队列：`invoice_id`、`tenant_id`、`error_msg`、`retry_count`、`status` |
| `partner_referrals` / `partner_commissions` | 渠道伙伴绑定关系与月度实收现金净额返佣结算表 |
| `gl_journal_entries` | 总账复式记账分录表（借贷试算平衡） |
| `fapiao_requests` / `dunning_cases` / `bank_statement_imports` / `approval_tickets` / `sla_credit_claims` | 数电发票、逾期催收、银行水单认领、大额双签审批与 SLA 赔付扩展业务表 |

## 二、常用 HTTP 鉴权头约定

- 租户门户接口（`/api/subscriptions/*`、`/api/usage/*`、`/api/wallet*`、`/api/invoices*`、`/api/fapiao*`）：请求头携带 `X-Tenant-Token: <租户 api_token>`。
- 运营财务管理后台接口（`/api/admin/*`）：请求头必须携带 `X-Admin-Key: <管理员密钥>`。
