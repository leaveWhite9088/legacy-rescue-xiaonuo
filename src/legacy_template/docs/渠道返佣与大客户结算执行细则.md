# 渠道返佣与大客户结算执行细则

- **文件编号**：YC-OPS-2025-014
- **签发日期**：2025-05-18
- **联合签发**：商业化渠道运营部、销售运营支持组、财务结算组
- **适用范围**：直客大客户事业部、区域总代理及认证二级分销商

## 一、渠道业绩核算与阶梯激励方案

1. **充值即计提激励机制**：为加快季度现金回笼，代理商名下绑定客户向现金钱包完成充值或缴存履约保证金当日，即可按到账金额全额计入当月渠道回款基数；客户使用活动赠送金抵扣账单的部分，按票面抵扣额的 `50%` 折算计入渠道季度评定业绩。
2. **双层代理管理补贴**：已备案的总代理商发展二级分销商后，二级分销商按自身签约费率结算分润，总代理商同步按总代签约基准费率全额领取渠道拓展佣金，作为区域市场联合赋能补贴。
3. **跨月退费平滑冲抵**：如客户发生历史账单退费，为保障代理商月度现金流稳定，当月渠道结算净额最低保底至 `0.00` 元（不生成负向倒扣结算单），超额退费顺延至下一年度总算。

## 二、大客户授信、变配与月结缓冲约定

1. **授信客户宽限保护**：凡签署年度框架协议且配置有授信额度（`credit_limit_cents > 0`）的企业客户，在账单到期后 `14` 个自然日且欠款未超授信额度期间，系统自动豁免 API 网关限流降级，并同步免除 `5%` 逾期违约滞纳金。
2. **周期中途降配差额折算**：客户在计费周期中途由高阶套餐切换至低阶套餐时，按当期剩余天数折算月费差额并自动充入客户赠送金账户用于后续抵扣。
3. **标准套餐含税价核算口径**：国内标准套餐目录价统一视作不含税净价，结算开单时在目录标价基础上另行加收 `6%` 增值税销项税额。
4. **月度关账申报前柔性调整期**：每月初执行上一自然月账期关账（`CLOSED`）后，在当月 `15` 日增值税纳税申报截止前设为财务柔性调整窗口，经事业部负责人邮件确认后可直接修订上一月原账单应付金额。
