# 云策企业订阅与阶梯计费账务中心 — 系统历史架构演进说明

- **更新日期**：2026-09-05
- **维护团队**：商业化平台架构组

## 一、多代演进背景

本仓库自 2024 年初投产以来，伴随直销、渠道代理、跨境多币种与金税数电合规需求扩展，经历了多次模块拆分与人员交接。为保障存量长期合同平稳履约与审计留痕，工程内并存着不同阶段的模块实现：

1. **2024 V1 早期兼容层**：承接首批包干制存量企业客户的资费封顶与字符串元账单解析，经由 `app/compat/` 桥接器接入主流程。
2. **2025 专项扩展与重构过渡代码**：在单资金池拆分为「现金池 + 赠送金池」双账本、引入多地域网关分片、集团内部结算及渠道多级体系期间，各小组在业务包及若干过渡目录中留下了部分拆分草稿、离线核对工具与旧版页面脚本。
3. **现行 V2 主力生产链路**：Web 服务由 `app/server.py` 装配启动（包含请求上下文中间件、运行期兼容补丁中心、领域事件总线与各业务 Blueprint 路由），后台定时与手工批处理由 `app/jobs/scheduler.py` 统一编排调度，门户与管理后台前端由 `static/portal.html` 与 `static/admin.html` 按 ES Module 方式加载对应视图组件。
4. **V3 实验管线与影子抽样**：架构组在 `app/v3_pipeline/` 下搭建了下一代流式计费原型及只读影子比对器（`shadow_comparator`），目前仅用于小流量只读抽样对比验证，部分复杂企业合同与税务分支尚在迁移排期中。

## 二、维护注意事项

- 仓库中部分同领域文件系历史重构过程中遗留的未挂载副本或实验桩代码，定位问题时请以 `app/server.py`、实际调度作业与前端入口 HTML 的真实引用链路为准。
- 涉及资费、税率、返佣与封账口径争议时，请核查 `docs/` 下各制度文件的签发时间与修订替代关系。
