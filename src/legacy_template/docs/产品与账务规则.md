# 云策企业订阅与阶梯计费账务中心 — 产品与账务规则

- **文件编号**：YC-FIN-2026-030
- **版本号**：v3.0
- **生效日期**：2026-08-20
- **效力说明**：本规则依据 `FIN-RES-2026-Q3-09` 联席决议修订发布，作为现行计量、定价、钱包、财资、税务、总账、渠道与内控核算标准。早期业务细则或需求文档中与本规则冲突的条款以本规则为准。

---

## 一、套餐目录、累进阶梯、企业协议与 SLA 赔付

1. **标准月度套餐与边际超额累进阶梯**：
   - `STARTER`（基础版）：`199.00` 元/月（`19900` 分），含 `10,000` 次调用，SLA 目标 `99.50%`（`9950` bps）。超额阶梯：`1～10,000` 次 `3` 分/次；`10,001～50,000` 次 `2` 分/次；`> 50,000` 次 `1` 分/次。
   - `PRO`（专业版）：`599.00` 元/月（`59900` 分），含 `50,000` 次调用，SLA 目标 `99.90%`（`9990` bps）。超额阶梯：`1～50,000` 次 `2` 分/次；`> 50,000` 次 `1` 分/次。
   - `ENTERPRISE`（企业版）：`1,999.00` 元/月（`199900` 分），含 `300,000` 次调用，SLA 目标 `99.95%`（`9995` bps）。超额统一 `1` 分/次。
   - 标准阶梯与自定义累计上限阶梯（`cumulative_bands`）均采用边际超额累进分段求和：各档上限含临界点本数，超出该上限的增量部分进入下一档计价。
2. **套餐变更、分段计量与退订**：
   - 期中升级套餐时，若运行期布尔配置 `waive_upgrade_proration_promo_window` 未开启，按 `30` 天标准周期折算当期剩余天数补差价 `(新旧月费差额 * 剩余天数) // 30`；期中降级或主动申请期末退订（`CANCELLED_AT_PERIOD_END`、`auto_renew = 0`）均不退还当期基础月费现金或赠送金。
   - 同一账期内发生套餐变更的，各时段产生的调用量归属事件发生时点的有效套餐，按对应套餐各自配额与阶梯独立核算超额费后合并汇总。
   - 订阅周期账单归属账期（`period_key`）统一取该计费周期起始日（`cycle_start`）所在的 `YYYY-MM` 月份。
3. **企业框架协议与 SLA 服务抵扣**：
   - 框架协议仅在状态为 `ACTIVE` 且计费周期起始日处于合同有效起止日期内时生效；核算顺序为先执行超额折扣与协议整单折让，再与合同约定的月度最低保底消费（`min_monthly_commit_cents`）取孰高补齐税前应收小计。
   - SLA 月度实测可用性低于套餐目标时，按档位发放不可提现贷项抵用单（`credit_notes`）：`>= 9900` bps 赔付当期基础月费 `10%`；`9500～9899` bps 赔付 `25%`；`9000～9499` bps 赔付 `50%`；`< 9000` bps 赔付 `100%`（单月最高赔付额以当期基础月费 `100%` 封顶）。处理完毕的赔付申报单状态须流转闭环（已赔付置 `CREDITED`，达标无需赔付置 `MEETS_SLA`），同一租户同账期不重复签发。
4. **2024 存量包干客户（`ACTIVE_LEGACY`）**：
   - 存量 `ACTIVE_LEGACY` 租户维持 `LEGACY_FLAT_99` 包干计费、合同封顶/折扣覆盖及历史 `YUAN_STR` 账单兼容解析，现代标准租户不可新签或转入该历史套餐。

## 二、计量采集、边缘心跳、时区转换与幂等

1. **有效用量校验与网关探活约定**：
   - 常规计费事件（单笔上报、批量上报及多地域分片归并）的 `quantity` 须为大于 `0` 的正整数，零值或负值请求返回 `400`。
   - **边缘网关探活特例**：单笔与批量上报通道支持边缘采集器发送 `event_type = "HEARTBEAT_PING"` 且 `dry_run = true`（`quantity = 0`）的连通性探活包；服务端收到该探活包须直接返回成功确认（不落库、不计入用量与重复数），不得将其误作非法零用量拦截。
2. **UTC 账期归属与跨区幂等累加**：
   - 带时区偏移的事件发生时间（`occurred_at`）须统一换算至标准 UTC（`+00:00`）后再提取 `YYYY-MM` 作为归属账期；若迟到事件归属月份已处于 `CLOSED` 封账状态，刷盘汇总时将其划入当前 `OPEN` 账期。
   - 相同 `event_id` 重试投递须保持全局幂等（已入库或缓冲事件再次到达时计入重复跳过，不重复累计亦不报错）；不同边缘可用区分片上报的同账期同指标用量须累加汇总。

## 三、双资金池钱包、并发结算、死信补偿与水单认领

1. **赠送金与现金分池核算**：
   - 账单扣款优先按到期日由近及远（`expires_at ASC`）核销状态为 `ACTIVE` 且未过期的赠送金批次，差额部分扣减现金池；到期清理任务仅核销未过期的剩余正数额度。
   - 账单退款须以该账单历史累计实付现金净额为上限退回现金池，超出部分退回赠送金池并恢复对应批次可用额度与状态。
   - 结算预览接口仅做无副作用只读试算（基于未付余额 `total_cents - paid_cents` 计算，不锁券、不改写共享资费配置）。
2. **支付幂等、自动出账与死信重试**：
   - 账单支付幂等键按 `(tenant_id, invoice_id, idempotency_key)` 三元组隔离作用域；周期续费出账仅针对正常在用且开启自动续费的订阅生成，同一订阅周期不得重复出账。
   - 自动扣款单笔失败时须回滚当笔部分扣款、保持账单 `OPEN` 并登记 `settlement_dlq`；存在未决争议冻结的账单跳过自动扣款与催收，当争议工单被驳回（`REJECTED`）后同步解除账单冻结态；死信重试仅补扣剩余未付差额并在结清后置为 `RESOLVED`。
3. **银企对公水单匹配**：企业户名比对时统一忽略首尾空白、常见公司组织形式后缀及中英文全半角括号差异；已自动或人工认领入账的水单不可重复认领。

## 四、多币种锁汇、跨境预提税、保证金与关联抵销

1. **外币锁汇与期末汇兑重估（CAS 19）**：
   - 外币账单折算采用账单周期起始日当日或之前最近生效的官方万分比牌价（`rate_to_cny_bps`），按四舍五入折算为人民币分值。
   - 月末汇兑损益重估仅针对期末仍未结清（排除已 `PAID` 及 `VOID`）的外币应收账单：期末牌价折算额高于初始入账人民币额计正数汇兑收益，低于初始入账额计负数汇兑损失。
2. **跨境预提所得税（WHT）与通道费**：
   - 标准云端 SaaS 订阅服务（`is_royalty_license = false`）免征特许权预提所得税（代扣税率为 `0`）；属于特许权许可授权（`is_royalty_license = true`）的款项，持有税收居民身份证明（`has_tax_residency_cert = true`）适用双边协定优惠税率（`treaty_royalty_wht_bps`），**未提供税收居民证明（`has_tax_residency_cert = false`）则必须按来源国法定标准预提税率（`standard_wht_bps`）计提**；合同约定税后净额包税倒算（`contract_gross_up_clause = true`）时，含税合同总额按 `round(净额 * 10000 / (10000 - 适用税率bps))` 计算。
   - 收单通道手续费仅对实收现金大于 `0` 的交易计收；履约保证金（`escrow_accounts`）抵缴欠款须同步核减保证金余额、登记支付明细并更新账单已付金额与结清状态；集团外部合并营收统计须剔除 `billing_metadata` 标记为内部关联交易（`intercompany` / `internal_settlement`）的结算主体。

## 五、税率档案、数电发票与总账摊销

1. **税率与数电开票**：
   - 国内含税档案 `CN_VAT_6_INCLUSIVE` 做价内税分离，国内价外税档案 `CN_VAT_6_EXCLUSIVE` 在税前小计外加收 `6%` 增值税，境外 `SG_GST_9_EXCLUSIVE` 不开具中国增值税发票且不纳入国内销项增值税申报汇总。
   - 数电蓝票及拆票预览均按账单累计实付现金净额（`实付现金 - 累计现金退费`）核算，不含税额按四舍五入拆分、税额由价税合计减不含税额得出以确保分位守恒，单张含税上限 `100,000.00` 元（`10,000,000` 分），同账单未冲红前仅限一张有效蓝票（`ISSUED`）。
   - 红字发票（`RED_ISSUED`）各项金额以负数入库并将原蓝票置为 `RED_REVERSED`；月度销项底账汇总须拉取全量分页并剔除已冲红原票（`RED_REVERSED`）与作废票（`VOID`）。
2. **复式总账（GL）与递延收入摊销（IFRS-15）**：
   - 每期非作废账单生成的复式总账凭证须严格借贷平衡（含存在跨期调账冲抵或补收差额的账单），现金退款须由事件钩子同步生成红字冲销凭证；赠送金滚存底稿须完整计入期间退款回充的赠金变动；话单-账单-总账三方勾稽按账单粒度聚合核对。
   - 多月预付合同剥离增值税后按不含税净额分月确认收入，整除尾差归入末月；期中合同变更重排摊销表采用未来适用法，已关账或已确认（`RECOGNIZED`）的历史月份保持不变。

## 六、渠道返佣、逾期催收停复机与内控安全

1. **渠道返佣**：仅统计渠道绑定生效后产生的账单实收现金，当期发生的现金退费在当期全额扣回（允许净现金与佣金为负，且不改动往期 `PAID_OUT` 记录）；季度等级评定按绑定生效后的实收现金净额核算；总代对二级分销商拿 `max(0, 总代费率 - 二级费率)` 管理级差。
2. **逾期催收与复机**：逾期账单按未付本金单次计提 `5%` 滞纳金；授信客户在 `14` 天内且欠款未超授信额时豁免接口限流（滞纳金正常计提）；`ACTIVE_LEGACY` 老客户受线下结算条款保护不执行自动停机；因逾期被置为 `SUSPENDED` 的现代租户在结清全部逾期欠款后自动恢复租户与订阅为 `ACTIVE`。
3. **四眼内控与账期封锁**：
   - 审批流申请人、一审人、二审人经空白裁剪与大小写归一化后须严格异号职责分离，审批决定仅接受 `'APPROVE'` 或 `'REJECT'`；单笔退款或调账绝对值 **`>= 5,000.00` 元（`500,000` 分）** 强制校验已终审通过（`APPROVED`）的关联审批单，**低于 `5,000.00` 元的常规小额退款与调账无需审批单即可直接办理**。
   - `CLOSED` 封账期账单、总账与历史确认表严禁原位修改；跨期调账单 `delta_cents` 负数为减免、正数为补收，每单仅限在 `PENDING` 状态下原子核销一次。
   - 经营分析活跃 MRR 仅统计状态为 `ACTIVE` 与 `ACTIVE_LEGACY` 的有效订阅，净现金回款率分子仅计当期账单实收现金净额。
