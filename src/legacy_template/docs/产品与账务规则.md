# 云策企业订阅与阶梯计费账务中心 — 产品与账务规则（内部规范 v2.4）

> 注：本文档汇总了产品计费、税务合同、渠道返佣与财务封账核心规则。部分早期历史代码存在技术债，排查问题时请结合线上代码实现与本规范综合研判。

## 一、标准套餐、阶梯计费与框架合同
1. **标准月度套餐**：
   - `STARTER`（基础版）：199 元/月（`19900` 分），含 `10,000` 次 API 调用。超额部分按超额累进阶梯计费：超额 `1～10,000` 次 `0.03` 元/次；超额 `10,001～50,000` 次 `0.02` 元/次；`50,000` 次以上 `0.01` 元/次。
   - `PRO`（专业版）：599 元/月（`59900` 分），含 `50,000` 次 API 调用。超额 `1～50,000` 次 `0.02` 元/次；`50,000` 次以上 `0.01` 元/次。
   - `ENTERPRISE`（企业版）：1,999 元/月（`199900` 分），含 `300,000` 次 API 调用。超额部分统一 `0.01` 元/次。
   - **累进原则**：所有套餐超额计费均采用**超额累进阶梯（Progressive Marginal Tiering）**，即分段计算各区间费用后求和，绝非按最高档单价全量倒推。
2. **大客户最低消费框架合同（`enterprise_contracts`）**：
   - 签署有效框架合同（`status='ACTIVE'`）的大客户，可享有专属超额费率折扣（`custom_overage_discount_bps`）；若当期折后税前小计低于合同约定的月度保底消费（`min_monthly_commit_cents`），系统自动按月度保底金额补齐税前基数。
3. **套餐升降配与退订规则**：
   - 同周期内**升级**套餐：按剩余周期比例折算补收差价（`proration_cents`）。
   - 同周期内**降级**或**主动退订**：当期已收或应计基础月费**一律不予退还**；退订后订阅状态转为 `CANCELED`（关闭自动续费），服务保留至当期结束。
   - **期中变配分段核算**：同一账期内发生套餐变更时，变更前后的用量必须分别归属各自发生时的有效套餐，按各段套餐自身的包含配额与阶梯单价分段独立计算超额费后再汇总，严禁将变更前高配额套餐下的用量混入变更后低配额套餐重算。
4. **2024 存量老租户商业兼容（`ACTIVE_LEGACY`）**：
   - 2024 年签约的 v1 老租户（`status='ACTIVE_LEGACY'`、`plan_code='LEGACY_FLAT_99'`、`schema_version=1`，含 `legacy_contract_override` 封顶条款、`legacy_discount_bps` 折扣及历史 `YUAN_STR` 字符串元账单）受存续商业合同保护，必须保持完整读取、展示与计费兼容，严禁删改或强制迁移。

## 二、税率档案与渠道返佣规则
1. **税率档案（`tax_profile_code`）**：
   - `CN_VAT_6_INCLUSIVE`（默认国内含税价）：标准标价已含 6% 增值税，价内拆税不额外加收（`tax_added_cents = 0`）。
   - `CN_VAT_6_EXCLUSIVE`（跨境/专票不含税协议价）：在税前账单小计基础上价外加收 6% 增值税（`tax_cents = round(subtotal * 0.06)`，计入应付总额 `total_cents`）。
   - `SG_GST_9_EXCLUSIVE`（新加坡主体不含税价）：价外加收 9% GST。
   - `EXEMPT`（历史免税/老合同）：税额为 0。
2. **渠道伙伴返佣（`partner_commissions`）**：
   - 绑定渠道码的租户按伙伴等级（`SILVER` 8% / `GOLD` 12% / `PLATINUM` 15%）核算月度返佣；返佣基数严格限定为当期已结清账单的**实收现金净额**（扣除现金退款），赠送金抵扣金额不产生返佣。

## 三、钱包、支付结算与滞纳金红线
1. **双账本资金守恒**：钱包分为**现金余额（cash）**与**赠送金余额（promo）**。支付账单时优先抵扣未过期的有效赠送金，不足部分扣减现金。
2. **退款原路退回**：赠送金严禁以任何形式变现！发生全额或部分退款时，必须严格按原支付单的现金/赠送金实付构成（优先退还现金或按实付上限切分，且退回现金绝不得超过原单实付现金、退回赠送金绝不得超过原单实付赠送金）原路冲回，同时同步恢复有效赠送金券额度。
3. **赠送金到期清零**：到期批处理仅允许扣减尚未消费的剩余额度，且必须具备幂等性；任何情况下钱包赠送金余额不得被扣成负数。
4. **并发幂等与状态机一致性**：
   - 手工支付、幂等重试与零点自动扣款并发执行时，同一账单严禁重复扣款，同一订阅周期严禁重复开具多张有效续费账单。
   - 自动结算批处理在扣款异常或余额不足时，严禁将账单永久遗留在 `PENDING_SETTLE` 中间态（未扣款应回退 `OPEN` 并记入死信队列 `settlement_dlq`；若已实际完成扣款则账单状态与实付金额必须一致落为 `PAID`）。
5. **逾期滞纳金**：对所有逾期未付账单统一按账单总额加收 **5%** 滞纳金（`late_fee_cents`），全平台统一执行，无任何行业或 VIP 等级豁免特权。

## 四、会计账期封账边界与审计准则
1. 账期为 `OPEN`（如当前 `2026-11`）时，允许正常计量刷盘、出账及错账订正。
2. 账期一旦由财务关账归档为 `CLOSED`（如 `2026-09`、`2026-10`），该账期内的所有历史账单记录（`invoices`）与账期归档总额（`archived_total_cents`）即受审计冻结保护，**严禁任何代码路径或手工 SQL 直接修改、覆写或作废**。
3. 若在关账后收到延迟到达的计量事件，或核实出已封账历史账单存在计费差额，必须将延迟用量或差额以**跨期调账记录（`billing_adjustments`）**的形式记入当前 `OPEN` 账期（注明 `ref_invoice_id` 与正负 `delta_cents`），保持历史封账凭证分毫不差。
